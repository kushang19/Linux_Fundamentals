-R (Uppercase): The flag that enables Recursive mode. 

`find . -type f -name "*.txt"`
Command Breakdown
find: The base command used to search for files and directories.. 
(Dot): Specifies the starting point of the search, which represents the current working directory.
-type f: Filters the search results to only look for files (excluding folders/directories).
-name "*.txt": Filters the results by name. 
The quotes and the asterisk * (wildcard) tell the system to match any filename that ends with the .txt extension.

`find . -type f -name "*.txt" | xargs cat`
| (Pipe): Takes that list of file paths and passes it as text input to the next command.
xargs: Grabs the list of file paths and passes them as arguments to the command that follows it.
cat: Reads the files and prints their actual contents to the screen.A Critical Alternative (Safer for spaces)

`find . -type f -name "*.txt" | xargs cat | grep "ERROR"`
The grep command (which stands for Global Regular Expression Print) is a powerful command-line utility used in Linux and Unix-like operating systems to search for specific words, phrases, or regular expression patterns inside text files or command outputs.

`find . -type f -name "*.txt" | xargs cat | grep "ERROR" | sort -k4 | uniq -f3`
sort -k4 (Sort by Key): The -k4 flag tells sort to use the 4th field (column) as the sorting key.
uniq -f3 (Unique Field Skip): The -f3 flag tells uniq (uniq requires sorted input because it only compares adjacent (neighboring) lines.) to skip the first 3 fields and only compare the text that comes after them.


`find . -type f -name "*.txt" | xargs cat | grep "ERROR" | sort -k4 | uniq -f3 > errors.log`
The > errors.log part of the command is called output redirection.It takes the final output generated by your command pipeline and saves it into a file named errors.log instead of printing it to your terminal screen.


`find . -type f -name "*.log" -exec cp {} ./backup \;`
-exec: This is a flag for the find command. It signals: "Hey, for every file that matches my search criteria, I want you to run an external command."
cp: This is the standard Linux command for copy.
{}: This pair of curly braces is a placeholder. find dynamically replaces {} with the path of the current file it is processing. For example, if it finds ./logs/2026-01/system.log, the command changes internally to cp ./logs/2026-01/system.log ./backup.
./backup: This is the destination folder where all the copied files will be placed.
\;: This terminates the execution string. The backslash (\) is required to escape the semicolon so your terminal doesn't think you are trying to write a completely new command line. It tells find: "This is the exact end of the command I want you to repeat."

`find . -type f -name "*.txt" -exec rsync -R {} ./backup \;`
Install rsync (If you want to keep using that command)
Once rsync is installed, this command behaves similarly to cp, but with one major advantage: it preserves your folder structure.
rsync: A powerful file-copying utility designed for efficiency.
